# astrbot_plugin_simple_reply

适用于 AstrBot `v4.26.5` 及更高 4.x 版本的宽松唤醒词插件。

AstrBot 默认只会在消息以唤醒词开头时唤醒。本插件将匹配方式扩展为“包含匹配”：只要消息任意位置包含配置中的任一唤醒词，就会进入 AstrBot 原生 LLM 回复流程，因此会继续使用当前会话、人格、上下文、工具和模型设置。

插件还支持群聊提及的二阶段意图判断：命中 `mention_keywords` 后，可先调用指定的对话模型判断消息是否真的在叫机器人，尽量过滤旁观讨论、复述、玩笑和“无需回复”的内容。

## 安装

在 AstrBot 管理面板中通过插件仓库地址安装：

```text
https://github.com/Aveousa/astrbot_plugin_simple_reply
```

也可以将本仓库目录放入 AstrBot 的 `data/plugins/` 后重载插件。

## 配置

在 AstrBot 管理面板的插件配置中修改：

- `宽松唤醒词`：字符串列表，默认值为 `AstrBot`。句首命中时直接触发；句中命中时，在启用意图判断的群聊中先进行判断，否则保持直接触发。
- `区分大小写`：默认关闭。关闭时 `AstrBot` 和 `astrbot` 均可命中。
- `群聊提及关键词`：字符串列表，仅群聊生效。用于补充句中提及机器人的关键词；句首命中时直接触发，句中命中时进入意图判断。
- `启用群聊意图判断`：默认关闭。开启后，提及关键词不会直接触发主 LLM，而是先由判断模型筛选。
- `意图判断模型`：可选择模型提供商；留空时使用当前会话的对话模型。
- `意图判断超时（秒）`：默认 3 秒。超时或模型调用失败时，本条消息不回复。

保存配置并按管理面板提示重载插件后生效。空字符串和只含空白字符的配置项会被自动忽略；当列表为空时，插件不会额外唤醒任何消息。

句首命中 `wake_words` 或 `mention_keywords` 时直接触发，不经过意图判断；只有群聊中非句首命中时才会进入判断模型。真实 @ 机器人或使用 AstrBot 原生唤醒前缀时，也不经过额外判断。两个列表可以配置相同的词。

## 日志

插件会使用 Info 日志记录唤醒词/群聊提及关键词命中、直接触发或进入意图判断、判断模型和超时时间，以及最终的“需要回复/无需回复”结果。为避免泄露聊天内容，日志不会记录完整消息正文。

例如，希望群聊中的“娅娅”先经过模型判断，可以配置为：

```json
{
  "wake_words": ["娅娅"],
  "mention_keywords": ["娅娅"],
  "enable_intent_judge": true,
  "intent_judge_provider": "你选择的对话模型提供商 ID",
  "intent_judge_timeout": 3
}
```

## 示例

唤醒词配置为 `小助手` 时：

```text
能让小助手帮我总结一下这段内容吗？
```

句中命中时会按上述配置决定是否经过意图判断；原始消息会完整保留并交给 AstrBot，不会删除句中的唤醒词。

# astrbot_plugin_simple_reply

适用于 AstrBot `v4.26.5` 及更高 4.x 版本的宽松唤醒词插件。

AstrBot 默认只会在消息以唤醒词开头时唤醒。本插件将匹配方式扩展为“包含匹配”：只要消息任意位置包含配置中的任一唤醒词，就会进入 AstrBot 原生 LLM 回复流程，因此会继续使用当前会话、人格、上下文、工具和模型设置。

## 安装

在 AstrBot 管理面板中通过插件仓库地址安装：

```text
https://github.com/Aveousa/astrbot_plugin_simple_reply
```

也可以将本仓库目录放入 AstrBot 的 `data/plugins/` 后重载插件。

## 配置

在 AstrBot 管理面板的插件配置中修改：

- `宽松唤醒词`：字符串列表，默认值为 `AstrBot`。消息包含任意一项即触发。
- `区分大小写`：默认关闭。关闭时 `AstrBot` 和 `astrbot` 均可命中。

保存配置并按管理面板提示重载插件后生效。空字符串和只含空白字符的配置项会被自动忽略；当列表为空时，插件不会额外唤醒任何消息。

## 示例

唤醒词配置为 `小助手` 时：

```text
能让小助手帮我总结一下这段内容吗？
```

即使唤醒词位于句子中间，也会触发 LLM 回复。原始消息会完整保留并交给 AstrBot，不会删除句中的唤醒词。

## 兼容性

- AstrBot：`>=4.26.5,<5`
- 无额外 Python 依赖
